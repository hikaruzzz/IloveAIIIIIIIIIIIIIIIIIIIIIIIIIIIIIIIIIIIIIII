# 妖股扫描

当用户调用 `/share-hot-stock-scan` 或提及「妖股」「打板」「连板」「涨停池」「妖股池」「扫板」「潜在妖股」时，按以下规则执行。

## 定位

本 skill 是 `hot-money-stock` 策略的**识别前置工具**。妖股不可预测连板高度，本 skill 只做两件事：

1. **识别**：全市场扫描具备妖股基因的标的（题材+涨停基因+结构）
2. **分级**：按情绪周期所处阶段（启动/确认/加速/末端）输出操作状态参考

## 数据存储

- 扫描结果保存 `data/scans/{YYYYMMDD}-hot-stock-pool.json`
- 同时向用户展示完整分级报告

## 操作流程

### 1. 执行扫描脚本

```bash
python3 scripts/hot-stock-scan.py [YYYYMMDD]
```

- 默认扫描当日；可传日期参数回溯历史
- 数据源：东方财富涨停板池接口（连板数/换手率/炸板次数/封单资金/流通市值/行业/近期涨停基因）
- 接口失败时：告知用户，降级提示改用 `/share-a-stock-data` 手动获取

### 2. 解读分级结果

脚本自动按以下规则分级（参数可在脚本中调整）：

| 级别 | 条件 | 含义 |
|------|------|------|
| 🔥 高度妖股 | 连板≥3 + 换手2.5-25% + 炸板≤2 + 流通市值≤150亿 | 情绪周期确认/加速期，市场焦点 |
| ⚡ 潜力妖股 | 连板=2 + 换手2.5-25% + 炸板≤2 + 流通市值≤150亿 | 启动确认期，试错窗口 |
| 👀 观察池 | 其余（首板/一字板/高炸板/大盘股） | 待确认或风险项 |

**特殊标签自动标注：**
- `一字板·无换手`（换手<2.5%且未炸板）→ 开板即核按钮风险，不追
- `加速末端·不追`（连板≥4）→ 情绪高潮区，持仓兑现/禁追
- `炸板N次·封板不稳`（炸板≥5）→ 资金分歧大
- `大盘·难妖`（流通市值>200亿）→ 拉升资金需求大，妖性弱
- `N日N涨停·基因强`（近期涨停≥4次）→ 妖股基因验证

### 3. 关联策略状态（输出必带）

对每只分级标的，结合 `hot-money-stock` 策略给出状态参考：

- 2板 → 试错窗口（≤10%仓位）
- 3板 → 确认期可加仓至≤20%
- 4板+ → 加速末端：持仓分批兑现/禁止追入
- 断板/破前日涨停价 → 离场信号

### 4. 输出格式

```
📅 {日期} 涨停池: 共 N 只涨停

🔥 高度妖股 (N只)
  {名称}({代码}) {价格}元 {连板}连板 换手{X}% 封单{X}亿 炸板{X} 流通{X}亿 [{行业}] 基因:{...} {标签}

⚡ 潜力妖股 (N只)
  ...

👀 观察池 (N只)
  ...

📌 策略状态参考 (hot-money-stock):
  ...
```

## 关键约束

1. **只识别，不预测**：绝不说「会连几板」「明天会涨」，只输出结构状态与纪律区间
2. **风控绑定**：输出必须附带 hot-money-stock 风控规则——单票≤20%、同题材≤30%、妖股策略资金隔离≤30%
3. **四板+强制警示**：连板≥4 必须标注「加速末端·不追」/「兑现区」
4. **一字板强制警示**：无换手一字板标注开板风险
5. **合规**：报告含风险提示「不构成投资建议」
6. **联动**：用户要求对池内个股深入分析时，调用 `/share-investment-analysis` 走全量策略匹配
